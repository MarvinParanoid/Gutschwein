# Shop logos

Drop `<slug>.png` here to replace the coloured tile in the list — the slug is the shop name
in lowercase with no spaces, e.g. `rewe.png`, `totalenergies.png`. Files are collected at
build time, so a shop without one is never requested.

Nothing is committed here on purpose: these are other people's trademarks, and shipping
them from a public repository is not our decision to make.
